# SHERU BHAI – ROYAL ENDLESS RUN

A polished, 60 FPS HTML5 Canvas 2D endless-runner arcade game starring **Sheru Bhai**, the royal white lion in a tailored three-piece suit, gold chain, and brown formal shoes.

## Features
- **Signature Character & 12 Animation States**: Idle, Run, Jump, Double Jump (360° flip), Slide, Landing squash, Coin sparkle, Damage flash, Victory, Game Over, Power-up aura, and Boss Roar Strike.
- **6 Unlockable Royal Kingdoms**: Royal Palace, Indian City, Desert Kingdom, Jungle Kingdom, Royal Fortress, and Future City — each with custom parallax backgrounds, ground design, obstacle sets, and procedural Web Audio music.
- **8 Power-Ups**: Royal Shield, Gold Magnet, Super Speed, Double Coin, Royal Flight, Invincibility, Mega Jump, and Time Freeze.
- **100 Functional Missions**: 10 Chapters × 10 Missions with automatic live tracking and LocalStorage persistence.
- **5 Boss Encounters**: The Royal Guard, Desert Beast, Jungle King, Iron Monster, and the 3-stage Final Boss **The Dark Lion**.
- **Character Shop & Trophies**: 8 unlockable Sheru Bhai skins and 10 Royal Achievements.
- **Zero-Dependency Local Execution**: Pure HTML5, CSS3, JavaScript, Canvas 2D, Web Audio API, and LocalStorage.

## Controls
### Desktop
- `SPACE` / `W` / `↑` — Jump & Double Jump
- `S` / `↓` — Slide (ground) / Fast Fall (air)
- `SHIFT` — Royal Roar Dash / Boss Strike
- `ESC` — Pause / Resume
- `ENTER` — Start or Retry

### Mobile / Touch
- **Tap** or **Swipe Up** — Jump & Double Jump
- **Swipe Down** — Slide
- **⚡ Button** — Activate Special Power

## How to Run
Open `index.html` directly in any modern browser (Chrome, Edge, Firefox, Safari) or serve the folder with any static HTTP server.
